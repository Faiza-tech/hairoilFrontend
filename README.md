# 🛍️ Hair Oil Ecommerce Frontend

A modern, responsive full-stack ecommerce frontend built with **React** and **Vite**, featuring customer shopping, secure authentication, Stripe checkout, and a complete admin dashboard for managing products, orders, users, and business analytics.

Designed with reusable components, scalable architecture, and a real-world ecommerce workflow.

# 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
